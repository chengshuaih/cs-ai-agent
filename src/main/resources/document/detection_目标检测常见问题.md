# 目标检测常见问题与解答

## 目标检测和图像分类有什么区别

图像分类只判断整张图像的类别，输出单一标签；目标检测需要同时定位图像中所有感兴趣目标的位置（边界框）并识别其类别，输出是一组带类别和置信度的边界框。

## 常见的目标检测模型有哪些

- 两阶段方法：Faster R-CNN，先生成候选区域再分类回归，精度高、速度相对慢。
- 单阶段方法：YOLO 系列、SSD、RetinaNet，直接在特征图上回归边界框，速度快，适合实时场景。
- Anchor-free 方法：FCOS、CenterNet，不依赖预设锚框，简化了超参数设计。
- 基于 Transformer 的方法：DETR 系列，用集合预测的方式端到端检测。

## 目标检测的核心评价指标

- IoU（Intersection over Union）：预测框与真实框的交并比，衡量定位准确度。
- Precision / Recall：精确率与召回率。
- AP（Average Precision）：单类别在不同召回率下的平均精确率，即 PR 曲线下面积。
- mAP（mean Average Precision）：所有类别 AP 的平均值。常用 mAP@0.5（IoU 阈值 0.5）和 mAP@0.5:0.95（多个 IoU 阈值取平均，COCO 标准）。
- FPS：每秒处理帧数，衡量推理速度。

## 小目标检测为什么困难，如何改善

小目标像素占比小、特征弱、易被下采样丢失。常用改善手段：

- 使用特征金字塔网络（FPN）融合多尺度特征。
- 提高输入分辨率或采用切图（tiling）策略。
- 数据增强中加入小目标复制粘贴（copy-paste）。
- 调整锚框尺度，使其覆盖小目标范围。

## 如何缓解类别不平衡

可使用 Focal Loss 降低易分样本权重，或在采样阶段对稀有类别过采样、对常见类别欠采样。
