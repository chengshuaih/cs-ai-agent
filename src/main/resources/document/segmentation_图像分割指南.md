# 图像分割常见问题与解答

## 语义分割、实例分割、全景分割的区别

- 语义分割：为每个像素分配类别标签，同类不同个体不区分（如所有"车"都是一类）。
- 实例分割：在语义分割基础上区分同类的不同个体（车1、车2分开）。
- 全景分割：统一处理可数物体（things）的实例分割与不可数背景（stuff）的语义分割。

## 常见图像分割模型

- U-Net：编码器-解码器结构 + 跳跃连接，医学影像常用。
- FCN：全卷积网络，语义分割的奠基工作。
- DeepLab 系列：引入空洞卷积与 ASPP 模块捕获多尺度上下文。
- Mask R-CNN：在 Faster R-CNN 上增加掩码分支，实现实例分割。
- SegFormer / Mask2Former：基于 Transformer 的统一分割框架。

## 图像分割的评价指标

- 像素准确率（Pixel Accuracy）：预测正确像素占比。
- IoU / mIoU：每个类别的交并比及其平均值，是语义分割主指标。
- Dice 系数：与 F1 类似，常用于医学图像，对小区域更敏感。

## 标注图像分割数据要注意什么

- 边界要尽量贴合目标轮廓，模糊边界需制定统一规则。
- 遮挡部分是否标注、如何标注需在规范中明确。
- 类别定义清晰，避免一物多标或漏标。
- 常用格式：COCO（多边形/RLE）、VOC（PNG 掩码）。
