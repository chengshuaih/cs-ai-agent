# 数据采集安全与隐私规范

本规范用于指导机器视觉数据采集过程中的现场安全、设备安全、隐私合规与数据管理，是采集计划生成与执行的基础约束。

## 1. 现场人身与交通安全

- 路口、车流密集区域采集时，采集人员必须站在人行道或安全岛内，严禁进入机动车道或在路口中央停留。
- 夜间或低照度场景采集应穿戴反光衣、佩戴照明设备，并尽量两人以上同行。
- 高速公路、隧道、桥梁、铁路沿线等区域禁止擅自停留采集；如确有需要，须提前向相关管理方报备并获得许可。
- 工业园区、厂区、施工现场采集前需获得场地管理方书面同意，并遵守现场安全规定（佩戴安全帽、避开作业区）。
- 雨雪、大雾、强风等恶劣天气应暂停户外采集，优先保障人员与设备安全。

## 2. 设备安全

- 三脚架、云台等设备应稳固放置，避免占用盲道、消防通道或妨碍行人通行。
- 无人机、车载相机等移动采集设备须遵守当地空域与道路管理规定，禁飞区严禁起飞。
- 电池、存储卡等耗材应做好备份与防护，避免高温暴晒或进水。

## 3. 隐私与合规

- 采集涉及行人、车辆时，应以群体场景为主，避免刻意、长时间针对特定个人进行拍摄。
- 不得采集涉及个人隐私的敏感区域（住宅窗户内部、ATM 输入区域、医院诊室等）。
- 含有人脸、车牌等可识别个人信息的数据，在对外展示或共享前应进行脱敏处理（打码、模糊）。
- 进入涉密、军事管理区、政府机关等禁止拍摄的区域，必须严格遵守现场标识与管理规定。
- 采集数据仅用于约定的研究与系统验证用途，不得用于个人识别、追踪或其他未授权目的。

## 4. 数据管理

- 原始数据应分场景、分时间归档，并记录采集地点、时间、天气、设备等元信息，便于后续标注与复现。
- 含个人信息的数据应限定访问范围，做好访问控制与备份。
- 不再需要的敏感原始数据应及时按规范删除。

## 5. 采集计划中的安全提示约定

系统在生成采集计划时，应针对每个推荐点位输出 `riskTips`（风险提示），至少覆盖：

- 交通与人身安全注意事项（如路口需站在安全位置）。
- 隐私与合规提示（如避免针对个人、注意脱敏）。
- 该点位特定的环境风险（如夜间照明不足、园区需报备）。
