# 机器视觉基础知识

## 什么是机器视觉

机器视觉（Machine Vision）是利用计算机和成像设备模拟人类视觉功能，从图像或视频中获取信息并进行理解、分析与决策的技术。它融合了图像处理、模式识别、深度学习与几何计算等多个领域，广泛应用于工业检测、自动驾驶、安防监控、医学影像等场景。

## 机器视觉的典型流程

一个完整的机器视觉任务通常包含以下环节：

1. 图像采集：通过相机、激光雷达等设备获取原始图像或点云数据。
2. 预处理：去噪、去畸变、亮度与对比度归一化、色彩空间转换等。
3. 特征提取：传统方法使用边缘、角点、纹理等手工特征；深度学习方法使用卷积神经网络自动学习特征。
4. 任务推理：根据具体任务进行分类、检测、分割或重建。
5. 后处理与决策：非极大值抑制、阈值过滤、结果融合，最终输出可用结论。

## 常见任务类型

- 图像分类：判断整张图像属于哪个类别。
- 目标检测：定位并识别图像中的多个目标，输出边界框与类别。
- 图像分割：在像素级别区分不同目标或区域，分为语义分割、实例分割与全景分割。
- 深度估计：从单目或双目图像推断场景的深度信息。
- 三维重建：从多视角图像或点云恢复物体或场景的三维结构。

## 常见挑战

- 光照变化：强光、逆光、夜间低光照会显著影响成像质量。
- 遮挡：目标之间相互遮挡导致信息缺失。
- 尺度变化：同一类目标在图像中可能呈现差异巨大的尺寸。
- 域偏移：训练数据与实际应用场景分布不一致，导致泛化能力下降。
