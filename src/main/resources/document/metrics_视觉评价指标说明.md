# 机器视觉评价指标说明

本篇说明机器视觉常见任务的评价指标，用于实验规划与结果评估时的指标选择参考。

## 1. 目标检测指标

- IoU（交并比）：预测框与真实框的交集面积除以并集面积，用于判定检测是否命中，常用阈值 0.5。
- Precision（精确率）：预测为正例中真正为正例的比例，衡量误检程度。
- Recall（召回率）：真实正例中被正确检出的比例，衡量漏检程度。
- AP（平均精度）：Precision-Recall 曲线下面积，针对单个类别。
- mAP（平均 AP）：所有类别 AP 的平均值。mAP@0.5 指 IoU 阈值 0.5 下的 mAP；mAP@0.5:0.95 指 IoU 从 0.5 到 0.95 多阈值平均，更严格。
- FPS（每秒帧数）：衡量推理速度，反映实时性。

## 2. 图像分割指标

- 像素准确率（Pixel Accuracy）：分类正确的像素占总像素的比例。
- mIoU（平均交并比）：各类别 IoU 的平均值，是语义分割的核心指标。
- Dice 系数：与 IoU 类似，常用于医学图像等场景，对小目标更敏感。
- 实例分割同时使用 mask mAP，结合检测与分割质量。

## 3. 深度估计与三维重建指标

- 深度估计常用：AbsRel（绝对相对误差）、RMSE（均方根误差）、δ 阈值准确率（如 δ<1.25）。
- 三维重建常用：点云的 Chamfer Distance、重建精度（accuracy）与完整度（completeness）。

## 4. 分类指标

- Accuracy（准确率）、Top-1 / Top-5 准确率。
- Precision / Recall / F1-score，适用于类别不平衡场景。
- 混淆矩阵用于分析各类别之间的误分情况。

## 5. 指标选择建议

- 实时检测任务需同时关注 mAP 与 FPS，在精度与速度之间权衡。
- 类别不平衡时优先关注 Recall 与 F1，而非单一 Accuracy。
- 数据集划分应保证训练/验证/测试集分布一致，避免指标虚高。
